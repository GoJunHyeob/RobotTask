ACT 과제 3 제출 상태

사용자 지정 원본: 다운로드/assignment_3.ipynb (빈 양식)
이전 ChatGPT 대화의 생성된 최종 노트북은 이 환경에서 접근할 수 없었음.
본 패키지는 사용자 지정 원본에 공개 설정, 실제 GIF, 손실 CSV를 반영한 실행본임.

완료
- 실제 GIF 3개 전체 40프레임 검사, 대표 클립 5.01초 확인
- 대표 클립의 주관적 부드러움: chunk10=2, chunk50=3, chunk100=3 (낮은 신뢰도)
- 회차별 점수로 복제하지 않음. 모든 회차의 note에 미평가 이유 기재
- 손실 CSV 시각화 및 100k 재평가 손실 기록 (원래 학습 로그와 구분)
- 공개 Hub 익명 접근 및 설정 일치 확인; 조회 시각·커밋 SHA 보관
- LeRobot 0.6.0 커널에서 코드 셀 13개 전체 실행, 출력 저장, 오류 출력 0개
- 모델 가중치를 이 패키지 또는 GitHub에 포함하지 않음

실제 실험 자료가 있어야 보완 가능한 항목
- 각 조건 10회 전체 영상/관찰 기록에 근거한 success, smooth, 위치 대응
- 성공/실패 판정 후 실패 원인 기록
- 등록 큐브 태스크와 대표 영상 속 병의 차이, 동일 시작 환경 및 fps 통제 확인
- 물체 5cm 이동 반응성 테스트 9회
- Temporal ensemble 평가 데이터셋과 10회 결과·추론 지연 비교
- 실제 터미널 실행 명령, GPU 모델, 학습 소요 시간 및 사전 가설 기록

배치 방법
저장소 루트에 이 패키지를 합치면 assignments/assignment_3.ipynb가 위치함.
기존 과제 1·2와 이미지는 삭제하거나 교체하지 말 것.
재실행은 assignments 폴더를 작업 디렉터리로 하여 Jupyter에서 Run All.
필요 패키지: pandas, matplotlib, pillow, ipykernel (보고서 코드); nbclient, nbformat (일괄 실행).
Hub 재검증은 새로 익명 조회해야 하며 현재 보고서 검사는 저장된 시점의 스냅샷을 사용함.
체크리스트의 미흡 항목을 임의로 통과로 변경하지 말 것.
